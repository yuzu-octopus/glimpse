## Findings considered and rejected

- **Negative `existsSync` cache poisoning** (scout P-04): `cachedExistsSync` memoizes misses, but all misses resolve inside `dist/` which is written once per deploy and never gains files mid-process; the write-once `distExistsCache` covers the only real path. Not worth a plan — revisit if dist ever becomes mutable at runtime.
- **`versionRef`/`versionBySlug` as dedupe identity** (scout's P-01 sketch): explicitly wrong — versions collide across polls by design (the comment at `usePageData.ts:510-513` says so). Recorded so nobody "fixes" it.
- **Removing `?? 1` renderer fallbacks after plan 002**: the fallbacks stay as last-line-of-defense rendering; plan 002 rejects the config at load instead. Do not "clean up" the fallbacks.
- **`../shared/theme.css`-style legitimate escapes** (plan 005 STOP box): fail closed. A future explicit opt-in is a separate decision, not part of 005.
- **Committing the `/tmp` benchmark** (plan 007): never. Numbers go in the index rejection entry if the optimization doesn't pay.
