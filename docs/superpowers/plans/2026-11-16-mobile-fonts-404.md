# Fonts 404 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make both JetBrains Mono weights load from the app's own `/fonts/` directory instead of the kit's unshipped `/astryx-dracula/fonts/` path.

**Architecture:** `astryx-dracula/tokens.css` declares the two `@font-face` rules with kit-relative URLs, but the server only ships `dist/fonts/`, so each font request hits the SPA fallback and returns HTML (200) instead of a font. `src/main.tsx` already imports `src/index.css` last; unlayered `@font-face` rules there with the same family/weight/style win the cascade, so two local overrides fix the URLs without changing import order. Preloads (`index.html`) and the PWA precache glob (`vite.config.ts`) already name `/fonts/*.woff2`; tests lock that alignment and a post-build check proves the emitted CSS is clean.

**Tech Stack:** Bun 1.4.4, React 19, Vite + vite-plugin-pwa, astryx-dracula 0.9.0, plain CSS, Vitest 5 with jsdom.

**Spec:** `/tmp/mobile-findings.md` — finding M01, reproduced verbatim:

> M01 — Fonts 404 (PERF-01, S, HIGH)
> Evidence: `node_modules/astryx-dracula/tokens.css:41,49` — `@font-face src: url("/astryx-dracula/fonts/JetBrainsMono-*.woff2")`; `dist/` has only `dist/fonts/` (verified); `index.html:15,22` preloads `/fonts/JetBrainsMono-*.woff2`; `src/server/index.ts:174-176` falls back to index.html for missing static paths, so font requests get HTML with 200. Impact: 183KB preload + SW precache wasted every load, two failed requests, all text renders fallback monospace. Fix: add local `@font-face` overrides after the kit CSS imports in `src/main.tsx`/`src/index.css` pointing at `/fonts/*.woff2` (files are already in `public/fonts/` and precached). Align preload/precache if needed. Verification: `bun run build` then check built CSS uses `/fonts/` URLs; add a source-level test that kit CSS overrides are imported after tokens.css.

## Review Focus

- A font URL pointing at a path the server does not ship returns HTML with 200 and text silently falls back — pinned by Task 1, `overrides both JetBrains Mono weights with served local files`.
- A partial fix that overrides only Regular leaves SemiBold broken — pinned by Task 1, the same test's two weight assertions.
- Moving `./index.css` before `tokens.css` silently restores the dead URLs — pinned by Task 1, `loads the font overrides after the kit tokens`.
- Preload or precache drifting back to the kit path wastes 183KB on every load — pinned by Task 2, `preloads the served font files` and `precache glob includes woff2 and both public font files exist`.
- A build that omits the local `/fonts/` overrides, or emits them before the kit faces, pins the regression — pinned by Task 2's post-build `rg` check and Task 1's import-order test. The kit's own `@font-face` rules intentionally remain in the bundle and are overridden by last-declared precedence (CSS Fonts 3 §4.6); their presence is NOT a failure.

- [ ] **Step 1: Write the failing test**

Create `src/fonts.test.ts`:

```ts
import { readFileSync } from "node:fs";
import { describe, expect, it } from "vitest";

const read = (p: string): string => readFileSync(p, "utf8");

describe("font delivery", () => {
	it("overrides both JetBrains Mono weights with served local files", () => {
		const css = read("src/index.css");
		expect(css).toMatch(
			/@font-face\s*\{[^}]*font-family:\s*"JetBrains Mono";[^}]*font-weight:\s*400;[^}]*src:\s*url\("\/fonts\/JetBrainsMono-Regular\.woff2"\)/,
		);
		expect(css).toMatch(
			/@font-face\s*\{[^}]*font-family:\s*"JetBrains Mono";[^}]*font-weight:\s*600;[^}]*src:\s*url\("\/fonts\/JetBrainsMono-SemiBold\.woff2"\)/,
		);
		expect(css).not.toContain("/astryx-dracula/fonts/");
	});

	it("loads the font overrides after the kit tokens", () => {
		const main = read("src/main.tsx");
		expect(main.indexOf('import "astryx-dracula/tokens.css"')).toBeLessThan(
			main.indexOf('import "./index.css"'),
		);
		expect(main.indexOf('import "astryx-dracula/theme.css"')).toBeLessThan(
			main.indexOf('import "./index.css"'),
		);
	});
});
```

	it("preloads the served font files", () => {
		const html = read("index.html");
		expect(html).toContain('href="/fonts/JetBrainsMono-Regular.woff2"');
		expect(html).toContain('href="/fonts/JetBrainsMono-SemiBold.woff2"');

		expect(existsSync("public/fonts/JetBrainsMono-SemiBold.woff2")).toBe(true);
	});
